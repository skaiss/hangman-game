
# Console Hangman Game (Виселица)
      __________
      | /   |
      |     O      
      |    /П\     
      |     LL    
      ==========
Простая консольная игра, написанная на Java. Ваша задача: угадать загаданное английское слово, прежде чем человек окажется на виселице.

## 🎮 Как играть

1. **Запуск:** При старте программа предложит вам выбор:
   * Нажмите `1`, чтобы начать новую игру.
   * Нажмите `0`, чтобы выйти из программы.
2. **Процесс:** Программа выбирает случайное английское слово из файла `words.txt`.
3. **Угадывание:** Вводите по **одной** английской букве в консоль.
4. **Правила:**
   * ✅ **Попадание:** Если буква есть в слове — она откроется на своих позициях.
   * ❌ **Промах:** Если буквы в слове нет — рисуется следующая часть виселицы.
   * ⚠️ **Лимит:** У вас есть **6 попыток** (ошибок), прежде чем игра закончится поражением.
5. **Победа:** Игра заканчивается вашей победой, как только все буквы в слове будут открыты!
