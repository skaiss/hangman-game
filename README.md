
# Console Hangman Game (Виселица)
      __________
      | /   |
      |     O      
      |    /П\     
      |     LL    
      ==========
     
Простая консольная игра "Виселица", написанная на Java. 
## 🎮 Как играть
1. При запуске введите `1` для начала игры.
2. Угадывайте буквы по одной.
3. У вас есть **6 попыток**, прежде чем игра закончится.
